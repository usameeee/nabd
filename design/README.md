# design/ assets
- logo/: app icon variants (1024x1024, no text, pure paths) + Android adaptive foreground (use emerald #0F5B46 as adaptive background color).
- splash/: splash screens light/dark. They use text + Google Fonts (Reem Kufi, Jost, IBM Plex Sans Arabic). For production, export PNG (1080x2454) after the fonts load, or convert text to outlines in Inkscape/Figma.
- The other screen mockups (home, viewer, diseases, quiz, reward, admin) were drawn in the chat and are NOT here yet. Re-create them in Figma from docs/01_BRAND_AND_DESIGN.md, or ask for SVG exports.
